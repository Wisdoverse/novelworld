# NovelWorld Implementation Entry Point

The original implementation blueprint duplicated the repository and had become
stale. Git history retains it; this file now routes readers to current sources:

- [`AGENTS.md`](./AGENTS.md) — runtime map, architecture constraints, commands,
  and coding conventions.
- [`docs/PRODUCT_CONTRACT.md`](./docs/PRODUCT_CONTRACT.md) — current supported
  envelope, evidence limits, and known gaps.
- [`SPEC.md`](./SPEC.md) — candidate normative behavior; not proof of current
  conformance.
- [`docs/ARCHITECTURE.md`](./docs/ARCHITECTURE.md) — current system and ownership
  boundaries.
- [`docs/ROADMAP.md`](./docs/ROADMAP.md) — dependency order and exit evidence.

Runtime code, migrations, and tests are the source of truth for current
behavior. Start Roadmap changes from one active Issue; do not implement a stale
checklist from repository history.
